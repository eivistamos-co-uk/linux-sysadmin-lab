# Linux Terminal for User Management:

## Files:

- ```/etc/passwd``` - users and info. Format: ```username```:```x```:```uid```:```gid```:```comment```:```home_directory```:```login_shell```

- ```/etc/shadow``` - users' passwords
- ```/etc/group``` - groups

## General Commands:

- ```id``` - Display current user and groups.
- ```who``` - Display logged in users.
- ```whoami``` - Print username.
- ```w``` - Show logged in users and what they are doing.
- ```uptime``` - Print how long system is running.
- ```last``` - Print log in / log out logs.

## Group Management:
- ```groups []``` - Display groups of user [].
- ```groupadd []``` - Create group with name [].
- ```groupmod []``` - Modify [] group.
- ```groupdel []``` - Delete [] group.

## User Management:
- ```useradd []``` - Create user account with name [].
- ```usermod []``` - Modify [] account.
- ```userdel []``` - Delete [] account.
