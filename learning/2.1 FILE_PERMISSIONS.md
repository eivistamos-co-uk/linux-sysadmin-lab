# Linux Terminal for the File System - Permissions:

## Display File Permissions:
- ```ls -l``` - List files in long format.
- ```stat []``` - display [] status. (Permissions/Timestamps/Ownership)

### Reference:
- ```r``` = Read
- ```w``` = write
- ```x``` = execute
- ```-``` = no access

## Octal Notation for Permissions:

- 7 Read, Write, & Execute
- 6 Read & Write
- 5 Read & Execute
- 4 **Read**
- 3 Write & Execute
- 2 **Write**
- 1 **Execute**
- 0 **No Permissions**

## Commands:
- ```chmod``` - Change file mode (permissions).
- ```chown``` - Change file ownership.
- ```chgrp``` - Change file group.
- ```lsattr``` - List file attributes.
- ```chattr``` - Change file attributes.

### Setting SUID:
Runs an executable with the file owner’s user ID.
- ```chmod 4XXX [filename]```

### Setting GUID:
Runs an executable with the owning group’s privileges.
- ```chmod 2XXX [filename]```

### Setting Sticky Bit:
Restricts deletion of files in shared directories to the file owner or root.
- ```chmod 1XXX [directory]```

## Examples:

- ```0777/-rwxrwxrwx```

- ```0644/-rw-r--r--```

- ```4755/-rwsr-xr-x```

An uppercase S would indicate SUID set without execute permissions.

- ```2750/drwxr-s---```

An uppercase S would indicate GUID set without execute permissions.

- ```1777/drwxrwxrwt```

An uppercase T would indicate Stikcy Bit set without execute permissions.
