# Linux Terminal Basics:

## Getting Help:
- ```man []``` - display manual page for [] command.
- ```type []``` - display type info about [] command.
- ```help []``` - display info about [] command. **For builtin commands only.**
- ```apropos []``` - search manual pages containing [] keyword.

## Terminal Shortcuts:
- ```TAB``` - Autocomplete. **Press twice for suggestions.**
- ```CTRL + L``` - Clear terminal by making space below.
- ```CTRL + D``` - Exit terminal.
- ```CTRL + U``` - Clear current line.
- ```CTRL + A``` - Move cursor to start of line.
- ```CTRL + E``` - Move cursor to end of line.
- ```CTRL + C``` - Stops current command.
- ```CTRL + Z``` - Sleeps command in foreground.
- ```CTRL + ALT + T``` - Opens terminal.

## Bash History:
- ```history``` - List history of commands used previously.
- ```!!``` - Repeat previous command.
- ```![int]``` - Repeat command on line [int] from history.
- ```![string]``` - Repeat command on last line starting with [string] from history.
- ```!abc:p``` - Print command on last line starting with [string] from history. 
- ```CTRL + R``` - Reverse search for command from history.

## Privilege Escalation & Root Access:
- ```sudo []``` - Run [] command as root.
- ```su``` - Become root temporarily.
- ```passwd []``` - Change password for [] user.
