# Linux Terminal for the File System:

## Paths:
- ```.``` - current working directory.
- ```..``` - parent directory.
- ```~``` - user's home directory.

## Viewing & Changing Directores
- ```pwd``` - print working directory.
- ```ls []``` - lists [] directory.
- ```cd``` - change to user's home directory.
- ```cd ~``` - change to user's home directory.
- ```cd -``` - change to last directory.
- ```cd []``` - change to [] directory.

### Tree Command:
**May need to be installed first:** 
```sudo apt install tree```

- ```tree []``` - print tree of [].

## File Types & Timestamps:
- **atime** - Last accessed time.
- **mtime** - Last modified time.
- **ctime** - Last (metadata) changed time.
---
- ```stat []``` - display [] status. (Permissions/Timestamps/Ownership)
- ```touch []``` - update [] times or create [] file **if not present.**
- ```date``` - print or set system date & time.
- ```cal``` - print calendar.
- ```file []``` - determine [] file type.

## Finding Files:
- ```which []``` - Locate [] command.
- ```plocate []``` - Finds all files with [] in name. **Use ```updatedb``` command to update plocate database**
- ```find [p] [o]``` - Finds files in [p] directory based on [o] options.
- ```grep [Regex] [F]``` - Search in [F] for text pattern that matches [Regex].

## Viewing Files:
- ```less []``` - Display contents of [] in terminal.
- ```tail []``` - Output last 10 lines of [].
- ```head []``` - Output first 10 lines of [].
- ```watch []``` - Execute [] command periodically and show results.
- ```wc []``` - line, word, and byte counts for [] file.
- ```strings []``` - print ASCII characters from [] binary file.


## Editing Files:
- ```cat []``` - Concatenate [] files and print result.
- ```mkdir []``` - Create a new [] directory.
- ```cp [S] [D]``` - Copy file from [S] to [D].
- ```mv [S] [D]``` - Move file from [S] to [D]. **Also used to rename**.
- ```rm []``` - Removes [] file.
- ```shred []``` - Overwrite file to hide contents. **Can also delete**.
- ```vim []``` - Display contents of [] through a text editor.
- ```tar``` - Archiving utility.
- ```gzip``` - Compress files.
- ```cut []``` - extract sections from [] based on criteria.
- ```tee []``` - prints input and writes to [] file.


## Comparing Files:
- ```cmp``` - Compare two files byte by byte
- ```diff``` - Compare two files line by line
