# Linux Terminal for Process Management:

- Add ```&``` to end of a line to run process in the background.

## Viewing Processes:

- ```ps``` - list processes started in current terminal.
- ```ps aux``` - list all processes in the system.
- ```pgrep []``` - look up processes based on [] name.
- ```pstree``` - display tree of all processes.
- ```top``` - dynamic display of processes.
- ```htop``` - interactive process viewer. ** May need to be installed first** 
- ```pidof []``` - find the process ID of [] process.

## Managing Processes:

- ```kill [pid]``` - send signal to [pid] process by Process ID.
- ```pkill [pname]``` - send signal to [pname] process by name.
- ```killall [pname]``` - send signal to all processes with [pname] in name.
- ```nohup [command]``` - run [command] immune to hangups.

## Job Management:

- ```jobs``` - show running jobs.
- ```fg [jid]``` - resume and bring to terminal a process by job ID [jid].
- ```bg [jid]``` - resume and bring to background a process by job ID [jid].
